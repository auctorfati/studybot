# Учебный бот: клиническая психология и английский

Telegram-бот для ежедневного самостоятельного обучения. Он работает как преподаватель: сначала даёт материал и объясняет его понятным языком, потом проверяет. Повторения бот выстраивает по интервальной сетке и сам собирает план дня под отведённое время. Открытые ответы, клинические виньетки и разговор на английском проверяет языковая модель, всё остальное — обычный код.

*A Telegram study bot for clinical psychology (Russian-language content with page-level source references) and an English-learning engine. Code under AGPL-3.0, content under CC BY-NC-SA 4.0.*

## Что внутри

Психология — семь областей входного среза по клинической психологии: 213 тем, 3 933 позиции банка вопросов и разборы ко всем темам (2 076 частей).

| Область | Код | Тем | Позиций | Виньеток |
|---|---|---|---|---|
| Патопсихология | PATO | 38 | 494 | 26 |
| Общая психопатология | PSY | 35 | 783 | 34 |
| Нейропсихология | NEURO | 28 | 726 | 21 |
| Классификации психических расстройств (МКБ-10, МКБ-11) | KLIN | 32 | 533 | 13 |
| Психоаналитическая диагностика | PSAN | 26 | 299 | 12 |
| Психология отношений | REL | 31 | 645 | 15 |
| Сексология | SEX | 23 | 453 | 13 |

У каждой области есть карта тем: что входит в область, какие вопросы закрывает каждая тема и до какого уровня её нужно освоить. Позиции банка идут по четырём уровням: термины и факты, механизмы (открытый ответ своими словами), различение близких понятий, применение на клинической виньетке. У каждой позиции есть ключ и ссылка на страницу источника, у виньеток — ещё и «угол наставника»: где проходит граница между поддержкой и направлением к специалисту. Разбор темы объясняет её обычным языком: что это, как устроено, чем отличается от соседнего, пример из практики, где читать.

Английский — движок без курса. Код поддерживает шесть модулей: от первых фраз о себе до свободного разговора и академического английского, с лестницей фразы, грамматическими заметками, контрольными точками, диалогами, монологами, слушанием и голосом. В `content/` лежит один демонстрационный банк с вымышленным персонажем: он показывает формат, и бот на нём сразу работает. Свой курс собирается по этому формату — он описан в разделе 2 демонстрационного файла. Модули 2–6 добавляют свои виды записей (истории, слушание, сценарии, темы разговора, тексты модуля 5); их формат пока описан только кодом — `studybot/content/english.py` и тестами.

## Как идёт обучение

Новая тема психологии начинается с разбора по частям. Потом идёт срез сверху вниз: если виньетка сразу получается, тема закрыта и её карточки уходят в повторение сразу с шага 14 дней; если нет — тема проходится по уровням. Повторения стоят на сетке 1, 3, 7, 14, 30, 60, 120 и 240 дней. При ошибке позиция откатывается на два шага сетки, а не к началу. Под каждым вердиктом есть кнопки «Почему так» (часть разбора), «Источник» (пересказ страницы источника, если источник подключён) и «Оспорить».

Время задаётся нормой дня: по умолчанию 90 минут в будни и 120 в выходные. Сессии запускаются кнопками на 5, 15 или 30 минут, есть вечерний блок и длинная воскресная сессия с кейсом. Норма, лимиты нового, время уведомления и другие параметры меняются прямо в боте: «Ещё» → «Настройки».

## Что нужно

Python 3.10 или новее и компьютер или сервер, который работает постоянно. Бот Telegram — токен выдаёт @BotFather. Свой числовой id в Telegram: бот отвечает только владельцу (id можно узнать, например, у @userinfobot). Ключ API языковой модели в формате OpenAI: в шаблоне конфига стоят модели Moonshot (Kimi), подойдёт любой совместимый сервис. Расход ограничивается дневным пределом `daily_budget_usd`; если предел исчерпан или модель недоступна, бот продолжает работать форматами, которые проверяет код. Для голосового режима нужен ключ Deepgram (распознавание и озвучка); без него бот работает текстом.

## Установка

```
git clone https://github.com/auctorfati/studybot.git
cd studybot
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp config.example.toml config.toml
chmod 600 config.toml
```

В `config.toml` заполните `telegram.token`, `telegram.owner_id` и `llm.api_key`, при необходимости часовой пояс и ключ Deepgram. Затем:

```
python -m studybot --config config.toml init-db
python -m studybot --config config.toml import content --apply
python -m studybot --config config.toml acceptance
python -m studybot --config config.toml run
```

`import content --apply` загружает весь контент в базу в нужном порядке: карты тем, банки, разборы, английский. `acceptance` — приёмка перед запуском: конфиг, база, импорт, копии, прогон 30 условных дней через бота без Telegram и без настоящей модели и автотесты, если установлены зависимости из `requirements-dev.txt`. Для постоянной работы на сервере есть шаблон сервиса `deploy/studybot.service`. Резервные копии бот делает сам: каждый день на диск, раз в неделю — документом в Telegram.

## Источники

Список литературы со всеми выходными данными — `docs/ИСТОЧНИКИ.md`. Тексты источников в репозиторий не входят: большая их часть защищена авторским правом.

Без источников бот проверяет ответы по ключу. Если у вас есть законные копии источников, их можно подключить: при импорте бот вырежет из них страницы, на которые ссылается позиция, модель будет проверять ответ по ключу и этим страницам, а под вердиктом появится кнопка «Источник». Формат файлов источников описан в `docs/УСТРОЙСТВО.md`, раздел «Источники».

## Важно

Это учебный материал для самостоятельного изучения психологии. Он не является медицинской или психологической помощью, не предназначен для диагностики и не заменяет специалиста. В материале возможны ошибки: у каждой позиции есть ссылка на страницу источника, сверяйтесь с ним. Если помощь нужна вам или близкому человеку, обращайтесь к врачу или психологу.

Карты тем, банки и разборы составлены по источникам с помощью языковых моделей и проверены скриптами: формат, существование страниц в источниках, отсутствие длинных дословных совпадений с текстом книг. Поправки и замечания — через Issues.
