# Источники

Каждая позиция банка и каждая часть разбора ссылается на источник и страницу: поле «Ист» в банке, ссылка в скобках в разборе. Ниже — выходные данные всех источников, на которые есть ссылки.

Коды источников действуют внутри своей области: S01 в психопатологии (PSY) и S01 в классификациях (KLIN) — разные работы. Буква кода показывает вид источника: K — классический учебник или руководство, N — нормативный документ, программа дисциплины или клинические рекомендации, S — статья или пособие. Три источника, общие для нескольких областей, обозначены словом: «Зейгарник», «CDDR», «ПООП».

Тексты источников в репозиторий не входят: значительная их часть защищена авторским правом. Статьи с пометкой открытой лицензии и документы ВОЗ можно найти по DOI или названию.
